# 作品集

邱怡青的海外用户增长作品集，围绕实际业务中的投放执行、内容生产、数据分析与流程管理，展示工具、方法和实践成果。

## 项目

| 项目 | 解决的问题 | 成果形式 |
| --- | --- | --- |
| AI 投放自动化助手 | 素材上传、文案生成与延迟深度链接提取中的重复操作 | 自动化脚本界面、产品文档与组内分享，工作效率提升近 100% |
| TikTok 素材跑出率分析看板 | 每日投放复盘与新旧广告问题定位 | TikTok API 取数、跑出分析与素材迭代协同 |
| 投放文案与深度链接工作台 | 文案调试、产品与素材主题适配 | 以两份 Skill 为基础，实际使用后逐步完善，为投放自动化做好前置准备 |
| TT / FB 本地化文案 Skills | 不同市场与平台的文案方法需要重复组织 | 两份可复用的本地化文案 Skill |

## 文案 Skills 原文

- [Facebook 广告文案生成](skills/FB文案生成.md)：面向 A1.art 的 Facebook 投放，每组 5 条标题和 5 条正文，附中文翻译。
- [TikTok 广告文案生成](skills/TT文案生成.md)：面向 Couplelens 的 TikTok 投放，每组 5 条短广告语。

两份文件保留用户提供的原始内容，包括产品语境、输入规则、趋势调研要求、批量输出格式、检查清单与示例。

## 站点

无需构建的静态网站，可直接部署到 GitHub Pages。首页为 `index.html`，项目介绍在 `data.js` 中维护，截图与奖项证明位于 `assets/`。

项目页面：

- `detail.html?project=ad-automation`
- `detail.html?project=runrate`
- `detail.html?project=workbench`
- `detail.html?project=ad-copy-skills`

所有站内资源均使用相对路径，适用于 GitHub Pages 的仓库子路径。截图可打开原图，Skill 可查看和下载。
